# Thai Dai - Thai Content Quality Standards

## Quality Assurance Framework

### 1. Romanization System
**Recommended: Paiboon+ System**
- Industry standard for Thai learning materials
- Consistent tone representation
- Used by Thai dictionaries and learning apps

**Alternative: IPA (International Phonetic Alphabet)**
- Most accurate for linguists
- Harder for beginners to read

### 2. Tone Representation (CRITICAL)
Thai is a tonal language - same word, different tone = different meaning

**Current Issues to Fix:**
- Add tone marks to all romanizations
- Examples:
  - มา (maa - come) vs หมา (mǎa - dog)
  - ไม่ (mâi - no/not) vs ไม้ (máai - wood)

**Tone Mark Standards:**
```
Mid tone: no mark     (maa)
Low tone: grave       (màa)
Falling tone: hat     (mâa)
High tone: acute      (máa)
Rising tone: caron    (mǎa)
```

### 3. Polite Particles (CRITICAL)
**Current Gap:** Only teaching male form (ครับ - krab)

**Must Add:**
- Male: ครับ (khrap/krab) - formal, ครับ (khap) - casual
- Female: ค่ะ (khâ) - formal, คะ (khá) - casual

**Teaching Approach:**
- Let user select gender in onboarding
- Show appropriate form throughout
- Or teach both with gender indicators

### 6. Recommended Content Order

**Priority 1 - Survival Thai (Week 1-2):**
1. Greetings + Wai gesture
2. Numbers + prices
3. "I want" + ordering food
4. Directions (left, right, straight, stop)
5. Taxi phrases + meter
6. "I don't understand" + "Please repeat"

**Priority 2 - Daily Life (Week 3-4):**
7. Days/times
8. Shopping + bargaining
9. Emergencies
10. Making friends

**Priority 3 - Integration (Week 5+):**
11. Small talk
12. Family terms
13. Work language
14. Cultural concepts (jai, sanuk)

### 7. Quality Check Process

**Before Publishing Each Lesson:**
1. Thai native speaker review
2. Expat beta tester feedback
3. Record audio with native speaker
4. Test on multiple devices
5. Cultural appropriateness check

**Ongoing:**
- User feedback collection
- Error reporting system
- Monthly content audits
- Community contributions (with verification)

### 8. Audio Quality Standards

**Options Ranked by Quality:**
1. **Best:** Native speaker professional recordings
2. **Good:** Web Speech API with Thai voice (current)
3. **Acceptable:** Text-to-speech with tone guidance
4. **Poor:** Synthetic beeps (removed)

**Recommendation:** Partner with Thai voice actors or use professional TTS services.

## Unit 4: Getting Around (Proposed Content)

### Lesson 1: Hailing Transport
- เรียกแท็กซี่ (rîiak tháek-sîi) - Call a taxi
- ไปที่... (pai thîi...) - Go to...
- กี่บาท (kìi bàat) - How many baht?
- กรุณาเปิดมิเตอร์ (ga-rú-naa pòoet mi-dtoo) - Please use meter

### Lesson 2: Directions
- เลี้ยวซ้าย (líaw sáai) - Turn left
- เลี้ยวขวา (líaw khwǎa) - Turn right
- ตรงไป (dtrong pai) - Go straight
- จอดตรงนี้ (jàwt dtrong níi) - Stop here

### Lesson 3: Common Driver Questions
- ไปไหนครับ (pai nǎi khrap) - Where to?
- ติดไหม (dtìt mái) - Traffic jam?
- ทางด่วนไหม (thaang dùan mái) - Highway?

### Lesson 4: Tuk-Tuk Negotiation
- แพงไป (paaeng pai) - Too expensive
- ถูกกว่านี้ได้ไหม (thùuk gwàa níi dâi mái) - Can cheaper?
- ไม่เอา (mâi ao) - I don't want
